Internship Tasks

Eight tasks. Thirty days. One platform you build yourself.

The TechBridge internship is a structured 30-day practical internship. You complete eight projects, one after another, and each one builds on the last, so your web development skills grow with every task.

How the internship works

Each task has a start day. When it opens, you build something real, and you carry what you made into the next task. By Day 26 you combine everything into one complete platform.

  • Learn by building. Every task ends with something you can open and use.
  • One step at a time. Tasks open on Days 1, 4, 8, 11, 15, 19, 22 and 26.
  • Harder as you go. Early tasks are beginner-friendly. Later tasks ask you to combine more skills.

The eight tasks, in order

Select “What you will build” on any task to see what you are expected to deliver.

  1. Day1

    Task 1

    Available from the start

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS.

    Beginner

    What you will build
    • A first working version of the TechBridge homepage
    • Page structure written in HTML5
    • Colours, spacing and layout styled with CSS
    • HTML
    • CSS
  2. Day4

    Task 2

    Opens on Day 4

    Build the TechBridge Programs Experience

    Create a Programs experience that presents TechBridge's available learning programs.

    Beginner

    What you will build
    • A Programs page that presents the available learning programs
    • The same look and feel as your homepage
    • Navigation that links the two pages
    • Page layout
    • Consistent styling
  3. Day8

    Task 3

    Opens on Day 8

    Build the Internship Tasks Experience

    Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

    Beginner → Intermediate

    What you will build
    • An interface that shows all eight internship tasks
    • A clear sequence that explains the journey
    • A layout that works on desktop, tablet and mobile
    • Responsive layout
    • Visual hierarchy
  4. Day11

    Task 4

    Opens on Day 11

    Build an Interactive Task Tracker

    Use JavaScript to make the internship task experience interactive and allow progress to be tracked.

    Intermediate

    What you will build
    • Your task experience made interactive with JavaScript
    • A way to track progress through the tasks
    • JavaScript
    • Interactivity
  5. Day15

    Task 5

    Opens on Day 15

    Build the Intern Registration Experience

    Create a professional registration/onboarding interface for TechBridge interns.

    Intermediate

    What you will build
    • A professional registration and onboarding interface
    • A form that is clear and easy for a new intern to complete
    • Forms
    • User experience
  6. Day19

    Task 6

    Opens on Day 19

    Build the Task Submission System

    Create an interface through which interns can prepare and submit their task work.

    Intermediate

    What you will build
    • An interface where interns prepare their task work
    • A way for interns to submit that work
    • Forms
    • Workflow design
  7. Day22

    Task 7

    Opens on Day 22

    Build the Intern Dashboard

    Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

    Intermediate → Advanced Beginner

    What you will build
    • A dashboard that shows an intern's profile
    • Views of their progress, tasks and submissions in one place
    • Dashboard design
    • Combining data views

    Opens on Day 26

    Intermediate → Advanced Beginner

    • Integration
    • Project completion
