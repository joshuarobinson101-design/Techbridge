Working with data and finding insights

Data Analytics

Learn practical data analysis: how to take raw information, prepare it, and turn it into answers that help a business decide what to do.

Skills you will develop

  • Spreadsheet analysis Organise and analyse data in spreadsheets.
  • Data cleaning Fix messy, incomplete or inconsistent data.
  • SQL Ask questions of data stored in databases.
  • Data visualization Present findings in clear charts.
  • Business-focused analysis Connect your results to real decisions.

A good fit if you enjoy spotting patterns, solving puzzles and asking "why?"

Apply for Data Analytics

Designing and building websites

Web Development

Learn practical website development: how to build pages people can visit and use, and how to manage your work like a developer.

Skills you will develop

  • HTML Structure the content of a web page.
  • CSS Style layouts, colours and typography.
  • JavaScript Make pages respond to visitors.
  • Git/GitHub Track changes and share your code.
  • Building web projects Put it all together in real sites.

A good fit if you enjoy creating things you can see, use and share.
